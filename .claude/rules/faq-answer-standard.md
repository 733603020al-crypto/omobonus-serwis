# Стандарт ответов FAQ (утверждён пользователем 2026-10-29, образец — /serwis-wysylkowy)

## Вид

- Шрифт и размер — как есть (Cormorant Garamond, 17 px на компьютере, 15 px на телефоне), не менять.
- Обычный текст — 600, выделенное — 700, цвет тёмно-коричневый #3A2817 (как сейчас).
- Отступ между абзацами — ~12 px на компьютере, ~10 px на телефоне (0,7em). Пустых строк между абзацами нет.
- Один общий стиль для всех FAQ (класс `.faq-answer-text`). Отдельные стили под пункт или страницу не создавать.

## Запись текста

- Абзацы разделяются пустой строкой в данных (`\n\n`) — это отдельный абзац с отступом, а не пустая строка на экране. Одиночный `\n` — перенос внутри абзаца.
- Выделение — разметкой `**…**`.
- Первая фраза, если это главная мысль ответа, — отдельным абзацем, выделена.
- В одном ответе не больше 1–2 выделенных фрагментов. Выделяем то, что клиент ищет глазами: цена, «бесплатно», главное обещание.
- Заключительная фраза — отдельным абзацем, без выделения.
- Повтор вопроса внутри ответа не пишем.
- Перечисления — отдельными абзацами, начинаются с «• », название пункта можно выделить (как на /serwis-wysylkowy).
- Сам текст ответа при оформлении не меняем (только разбивка на абзацы и выделение), кроме явных опечаток/запятых по согласованию.

## Чек-лист

1. Нет повтора вопроса в начале ответа.
2. Главная мысль — первой строкой, выделена (если есть).
3. Выделений не больше 1–2.
4. Вывод — отдельным абзацем, обычным текстом.
5. Проверка на 1440 и 390: абзацы читаются отдельно, нет пустых строк, нет «стены текста».
6. Все языки (PL, UK, RU, EN) оформлены одинаково.
