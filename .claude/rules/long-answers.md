# Длинные ответы

## Что это
Если ответ или отчёт длинный, в чате пишу короткое резюме, а полный текст сохраняю отдельным файлом (HTML) вне проекта и открываю в браузере. В файле ничего не сокращаю, есть кнопка «Скопировать всё».

## Важно
При подготовке исследований, выводов и отчётов ничего не добавлять и не изменять в проекте: ни код, ни инструкции, ни правила, ни служебные файлы. Запись правила — только по отдельному прямому поручению пользователя.
Все материалы одной задачи объединять в один самостоятельный HTML-файл вне проекта, без разделения на несколько файлов отчёта. Открывать его в Chrome; сверху обязательна кнопка «Копировать», копирующая весь отчёт целиком.

## Длинные ответы, анализы и технические отчёты (действует всегда)

Любой длинный ответ, анализ или технический отчёт, который не помещается в короткий ответ: краткое резюме — в ответе, полная версия без сокращений — отдельным HTML-файлом вне проекта. В HTML ничего не сокращать — там весь ответ целиком.

- В HTML-отчёте — кнопка «Скопировать всё», копирующая весь текст отчёта одним нажатием (если среда это поддерживает).
- Локально на компьютере пользователя (Windows): `%TEMP%\claude-answer.html`, затем открыть в Chrome. Перед завершением задачи проверить, что файл записан и открыт, кнопка копирования находится сверху и работает.
- В Claude Code Web и других облачных средах: сохранить файл во временной папке среды и передать его пользователю в чат. Не обещать открыть файл в Chrome пользователя, если среда этого технически не позволяет.

Внутри проекта такие отчёты не создавать.
