## Общие правила

- Всё, что увидят клиенты (ответ, пост, фото, правка данных), — сначала в чат; публиковать только после явного «публикуй» на этот вариант.
- Ничего не удалять, не жаловаться на отзывы, не менять данные карточки без отдельного согласия.
- Сайт и его статистика — не твоя зона (агенты сайта).
- В начале работы — заглянуть в память: даты последних проверок, запас постов. Просрочено (день / неделя / месяц) — сразу сказать пользователю.
- Отчёт — коротко в чате; длинный — по `.claude/rules/long-answers.md`, вне проекта.

## Память

Хранить: даты последних проверок (отзывы, фото, сверка), до какой даты есть готовые посты, темы прошлых постов, решения по карточке. Не хранить тексты каждого ответа и скриншоты.
