# Новый язык сайта

Образец — EN `/en` (ЭТАПЫ 182–189 в `AI_WORK_STATE.md`, коммиты `233fd5e`, `fdad4f1`). Общие правила — `docs/languages/languages-standard.md`. `XX` — код языка, `/XX` — префикс.

PL — источник. Новый язык = смысл и структура PL через общие шаблоны и данные; JSX не копировать. Цены, сроки, контакты, NIP, адреса, бренды — как в PL.

## 0. Подготовка
1. Worktree и ветка `pages/XX-version` от свежего `origin/test`, свой порт. Создавать только по согласованию.
2. Одна сессия — одна папка. Спросить, не идёт ли работа над языком в другой вкладке.
3. Спросить: зачем язык, код страны для флага, выпадающий список или отдельная кнопка.
4. Страницы закрыты от индекса до утверждения SEO.
5. Заранее попросить подключить Chrome (GTM, CookieYes — п. 7).

- Интерфейс: `src/lib/i18n/XX.ts` (по `en.ts`), `i18n/service-accordion.ts`, `i18n/google-reviews.ts`.

## 6. Публикация
1. Влить свежий `origin/test` в `pages/XX-version`.
2. Один коммит со всей версией, вместе с юридическими страницами; только по разрешению.

## 8. Технические ловушки
- Git Bash превращает `/kontakt`, `/en` в `C:/Program Files/Git/...`: `MSYS_NO_PATHCONV=1`. `node` не понимает `/c/Users/...` — `C:/Users/...`.
- Скрипты с `\`, `\u`, апострофами в heredoc/`sed` ломаются: писать файлом (Write), запускать `node файл.cjs`; для `\u00a0` — `String.fromCharCode(92)`.
- CRLF/LF: не вставлять `\r\n` в LF-файлы; в CRLF — привести к LF, заменить, вернуть.
- `node_modules` для worktree и копии сборки — junction через PowerShell `New-Item -ItemType Junction` (`mklink /J` через `cmd //c` не работает).
- Старый node остаётся на порту после остановки: перед перезапуском проверить порт, завершать по PID, только убедившись по командной строке, что это сервер этой папки.
- Lighthouse на Windows: ненулевой код часто лишь ошибка очистки temp; прогон удачен, если отчёт записан; старый отчёт удалять перед прогоном. `robocopy` код 1 — успех.
- `sed` по номерам строк ломается при изменении файла: Edit или `node` с точным совпадением и проверкой числа замен; по хабу услуг ограничивать замену блоком нужного `slug`.
