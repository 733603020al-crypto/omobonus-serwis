# Стандарт оформления пунктов вопросов (аккордеон `.questions-accordion`)

Утверждён пользователем 2026-10-29, образец — /serwis-wysylkowy. Единственный источник правды. Область: текст ответов FAQ — на ВСЕХ страницах сайта (PL, UK, RU, EN оформлены одинаково); карточки infoCards и связанные элементы — блок вопросов с классом `.questions-accordion` (компонент `service-accordion.tsx`, сейчас /serwis-wysylkowy).

- Текст ответов FAQ (`faq-answer-text`) — единый стандарт для всего сайта, включая страницы /uslugi.
- Название вопроса (заголовок пункта аккордеона) — по price-card-standard.md, отдельно здесь не задаётся.
- Цены: в таблицах прайса — по price-card-standard.md; в карточках infoCards — по этому стандарту.

## Основной текст

- Основной текст, абзацы, строки «–»: класс `faq-answer-text` — Cormorant Garamond, компьютер 17 px / телефон 15 px, вес 600, выделенное 700, цвет #3A2817. Шрифт и размер не менять.
- Цифры ровные: `font-variant-numeric: lining-nums`. Действует для всех FAQ сайта (общее правило `.faq-answer-text`).
- Отступ между абзацами ~12 px на компьютере, ~10 px на телефоне (0,7em). Пустых строк между абзацами нет.
- Один общий стиль для всех FAQ. Отдельные стили под пункт или страницу не создавать.

## Карточка (infoCards)

- Компонент `infoCards`: золотая рамка, текст слева, картинка справа; на телефоне картинка под текстом.
- Заголовок карточки: `info-card-title` — 20 px / 17 px, вес 600, всегда слева. Левый край текста = левый край заголовка, без дополнительных отступов.
- Строки с ценой: текст — `faq-answer-text`; число — `font-inter`, 17 px / 15 px, вес 600; «zł», «od», «ok.» — как текст; между строками тонкие линии.
- Примечание к карточке: `parentheses-caption-text dojazd-promo-caption` (16 px / 15 px), внизу карточки, слева, без фона.
- Примечание ко всему пункту: `noteBanner` — полоса сверху по центру.
- Картинка в карточке: `info-card-image` — компьютер высота 200 px, ширина до 320 px; телефон ширина 100 %, высота до 220 px; `object-fit: contain`. Фон картинки прозрачный.
- Таблица прайса внутри пункта — общая таблица прайса сайта, без изменений.

## Запись текста ответа

- Абзацы разделяются пустой строкой в данных (`\n\n`) — это отдельный абзац с отступом, а не пустая строка на экране. Одиночный `\n` — перенос внутри абзаца.
- Выделение — разметкой `**…**`.
- Первая фраза, если это главная мысль ответа, — отдельным абзацем, выделена.
- В одном ответе не больше 1–2 выделенных фрагментов: то, что клиент ищет глазами (цена, «бесплатно», главное обещание).
- Заключительная фраза — отдельным абзацем, без выделения.
- Повтор вопроса внутри ответа не пишем.
- Перечисления — отдельными абзацами, начинаются с «• », название пункта можно выделить.
- Короткий список строк (перечень, сроки) — один абзац с переносами строк. Отдельные абзацы — только для самостоятельных мыслей из нескольких предложений.
- Сам текст ответа при оформлении не меняем (только разбивка на абзацы и выделение), кроме явных опечаток/запятых по согласованию.

## Правила для ИИ

- Новые пункты и карточки собирать ТОЛЬКО из этих элементов.
- Не вводить новые размеры шрифта, цвета, отступы и классы оформления. Не добавлять Tailwind-классы размера/цвета текста (`text-[..px]`, `text-white` и т.п.) — в этом блоке они перекрываются и вводят в заблуждение.
- Если нужен элемент, которого нет в стандарте, — сначала спросить владельца, не придумывать.

## Чек-лист

1. Нет повтора вопроса в начале ответа.
2. Главная мысль — первой строкой, выделена (если есть).
3. Выделений не больше 1–2.
4. Вывод — отдельным абзацем, обычным текстом.
5. Проверка на 1440 и 390: абзацы читаются отдельно, нет пустых строк, нет «стены текста»; карточки — по списку выше.
6. Все языки оформлены одинаково.
