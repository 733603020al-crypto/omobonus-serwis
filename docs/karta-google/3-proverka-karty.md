# Задача 3. Проверка данных карточки

**Как часто**
- Раз в день (вместе с отзывами): нет ли правок, предложенных Google или другими людьми («Google обновил данные»).
- Раз в месяц: полная сверка карточки с сайтом.

**Что сверять раз в месяц:** название, адрес, телефон, сайт, часы работы, категории, описание, список услуг и цены (как на сайте, netto), атрибуты.

**Правила**
- Источник правды — сайт.
- Карточка не совпадает с сайтом — показать пользователю расхождение и предложить правку; менять только после согласия.
- Перед праздниками — напомнить про особые часы работы.
- Сайт этот агент не меняет и статистику сайта не разбирает — это задачи агентов сайта.
