# Задача 4. Звонки клиентам после ремонта — ОТЛОЖЕНО

**Статус:** не начинать, пока не появится журнал клиентов/ремонтов. Напоминать пользователю об этой задаче при ежемесячной проверке карточки.

**Идея (когда будет журнал)**
- По журналу находить клиентов, у которых недавно закончился ремонт.
- Напоминать сотруднику: позвонить клиенту, спросить, всё ли в порядке с техникой, и попросить оставить отзыв в Google.
- Отмечать в журнале, кому уже позвонили, чтобы не звонить дважды.

Детали (через сколько дней звонить, кто звонит, как напоминать) — решить вместе с пользователем, когда будет журнал.
