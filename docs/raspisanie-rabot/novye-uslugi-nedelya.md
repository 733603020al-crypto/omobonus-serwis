# Новые услуги в карусели «Serwis wysyłkowy» (раз в неделю)

Цель: каждая услуга-техника из верхнего меню есть в карусели страницы «Serwis wysyłkowy». Бегущая строка берёт услуги из меню сама, карусель — нет.

## Проверка
1. Взять из `src/config/service-categories.ts` (`SERVICE_CATEGORIES`) все пункты без `menuOnly` и без `notDevice`; из `href` взять последнюю часть (slug).
2. Сравнить со списком `SLUGS` в `src/components/serwis-wysylkowy/sections/home-hero-showcase.tsx`.
3. Всё есть — записать дату в таблицу, пользователю ничего не писать.
4. Есть услуги без слайда — сказать пользователю простыми словами, каких именно, и попросить картинку для карусели (первый слайд страницы услуги подойдёт).

## Как добавить услугу (по разрешению пользователя)
В `home-hero-showcase.tsx` дописать по одному значению в каждый список рядом с `SLIDES` (картинка, `SLUGS`, размеры, сдвиг по вертикали) и по одной подписи заголовка в `mids`: польская — `sections/hero.tsx`, украинская/русская/английская — `i18n-hero.ts`. Порядок — как в меню. Проверить `?from=<slug>` на странице «Serwis wysyłkowy».
