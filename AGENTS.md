# Правила

- **Главное правило для Кодекса: бери все правила из `CLAUDE.md` и файлов, на которые он ссылается (`docs/claude/`, `docs/seo/`, `docs/languages/languages-standard.md`, `.claude/rules/`). Отдельных правил для Кодекса нет: всё, что написано для Claude, действует и для тебя.**
- Перед правкой цен, сроков или текстов в `services-data*.ts` прочитай раздел «Цены, сроки и синхронность» в `docs/languages/languages-standard.md`; перед коммитом — `npm run check:i18n-sync`.

## Единая структура: писать только сюда
Все правила, инструкции и стандарты — только в `CLAUDE.md` (указатель) и файлах `docs/claude/`, `docs/seo/`, `docs/languages/languages-standard.md`, `.claude/rules/`; они видны в панели (Конфигурация ИИ → Правила). Отложенные задачи — только в журнале панели (`omobonus-workspace/tasks`). Новый файл или папку правил создавать только после вопроса пользователю и его разрешения; сначала предложить подходящий существующий раздел и спросить. Правила, которые нужны только одному ИИ, — отдельным разделом в подходящем файле с пометкой, для кого.
